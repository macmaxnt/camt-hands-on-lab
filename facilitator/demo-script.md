# Ten-minute opening demo / สคริปต์สาธิต 10 นาที

1. **0:00-2:00 - Boundary.** Say: “This assistant knows only these eight approved readings. It does not browse and it does not guess.” / “ผู้ช่วยนี้รู้จากเอกสารที่อนุมัติ 8 ชุดเท่านั้น ไม่ค้นเว็บ และไม่เดา”
2. **2:00-4:00 - First principle.** Use the lecture slide: retrieval selects evidence before answering. Explain direct lookup, keyword search, and semantic search.
3. **4:00-6:00 - Retrieval.** Open the notebook and show document chunks, lexical matching, a query vector, similarity score, and metadata.
4. **6:00-8:00 - Grounded answer.** Ask the data-privacy question in both keyword and semantic mode. Open the citation and read its source location.
5. **8:00-9:00 - Safe failure.** Ask about CAMT tuition and explain why declining is safer than inventing an answer.
6. **9:00-10:00 - Ambiguity.** Ask “Should schools use AI?” Show the clarification status; name privacy, bias, pedagogy, and accountability as focused follow-ups.
