# Pre-session checklist / รายการตรวจสอบก่อนสอน

Complete these today, in order.

- [ ] Create the GitHub Classroom assignment and publish the repository URL. State two entry routes: continue a prior milestone or use `starter/rag-v0`.
- [ ] On a clean machine with Node 20, run `npm install`, `npm test`, `npm run build`, and `npm run dev`.
- [ ] Open the notebook in Google Colab. First run the fallback route, then upload `corpus/source-pdfs/unesco-genai-guidance.pdf` and set `USE_FULL_PDF=True` to confirm page extraction and chunking. Finally test the optional embedding cell once with internet. The fallback must still work if that download fails.
- [ ] At script.google.com, paste `assessments/create_forms.gs`, run `createRagLabForms`, authorize it, preview both Forms, and submit one test response to the linked sheet.
- [ ] Disable email collection in both Forms. Keep only the anonymous learner-code field for pre/post comparison.
- [ ] Practice the demo script and save its three expected screenshots in a facilitator folder.
- [ ] Post `evidence/test-prompts.md`, `evidence/evidence-log.md`, `evidence/rubric.md`, and `evidence/submission.md` in the Classroom assignment.
- [ ] Download a ZIP copy of this kit to a USB drive or local folder as a recovery route.
