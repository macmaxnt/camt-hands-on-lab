# Lab 3: Bounded Agentic AI

Build `agent-v3`: an agentic workflow that investigates with approved tools, maintains observable state, and asks for approval before external action.

## Planned entry points

- Notebook: `03_bounded_agent.ipynb`

## Boundary

The lab will teach goals, state, tools, feedback, and stop conditions through a bounded workflow rather than an unrestricted autonomous agent.
